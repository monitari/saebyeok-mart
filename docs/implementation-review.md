# 전체 개선 항목 반영 기록

이 문서는 초기 기능 구현과 실제 검증을 구분한다. 화면을 직접 보고 재미와 배치까지 검증했다는 의미는 아니다.

| 제안 항목 | 이번 반영 |
|---|---|
| 1. 실제 화면 검증 | HTML 구조·요소 연결 검증 추가. 연결된 브라우저가 없어 실제 배치 확인은 미완료 |
| 2. 시간 흐름 | 기본 하루 약 24분, 설정에서 48/24/12분 선택. 따라가는 인물의 중요한 대화 자동 감속 |
| 3. 모델 대기 | 전송된 요청은 현실 시간 8.5초 예산. 게임 배속으로 기한이 줄어들지 않음 |
| 4. 연결 확인 | 모델 목록과 생성 시험 분리. 모델 후보 선택, JSON·대사 검증, 실제 지연 표시 |
| 5. 알림 중요도 | 종류·참여자별 간격. 반복 일상 알림은 종류당 하루 한 번. 기록은 별도 보관 |
| 6. 녹화 범위 | 최근 게임 시간 2분의 사전 기록, 대화 종료 후 짧게 마무리. 모델 대기 중 정지 자세로 프레임 낭비 방지 |
| 7. 제목과 사건 연결 | 진행 중 제목과 확정 제목 분리. 효과가 실행된 실제 대화 ID로 연결 |
| 8. 장면 보관 | 최근 8개 외에 최대 4개 간직하기. 저장·내보내기에 포함 |
| 9. 성격의 행동 | 기존 구매·대기·청소 차이에 통로 양보와 짧은 정지 추가 |
| 10. 상황에 따른 변화 | 주간 생활 변화가 급함·피로·방문 시각·선호에 영향 |
| 11. 일행 | 기존 함께/각자 계산·기다리기 유지. 3주마다 새 산책 이웃 모임 생성 가능 |
| 12. 기억의 행동 결과 | 기존 우산 반납·물건 보관·화해 유지. 생활 소식은 실제 듣는 사람만 기억 |
| 13. 장기 변화 | 주간 새 손님, 6일 동안 지속되는 생활 변화와 만료, 생활 기록 상한 |
| 14. 운영 선택 | 매트·조명·담배 판매대 추가. 물기·기분·구매 유형에 연결 |
| 15. 경영 부담 | 시설 최초 구입비, 하루 운영비 12,000원. 부족하면 보유 현금까지만 지출하는 완화된 초기 규칙 |
| 16. 하루 경계 | 매출·방문·반납·미해결 일·주요 사건의 영업일지 14일 보관, 최근 7일 표시 |
| 17. 소리 | 합성 환경음과 생활 소리, 최초 음소거, 사용자 입력으로 켜기, 환경/효과 음량 분리 |
| 18. 외형 | 주 단위 상의 색 변화, 외형까지 포함한 렌더 캐시. 실루엣·체형·자세는 기존 유전자 사용 |
| 19. 의미 검사 | 한국어·숫자·상품·모르는 이름·미지원 약속·인사/작별 검사. 사실/거래 대사는 규칙 유지 |
| 20. 여러 탭 | Web Locks 단일 작성자. 나머지 창은 실행·저장 중지, 기존 창 종료 후 재획득 |
| 21. 멈춤과 취소 | 설정·다시 보기·일시정지·숨김·읽기 전용에서 결과 보류. 설정 변경/세이브 교체 때 이전 요청 취소 |
| 22. 과거 외형 | 장면 생성 당시 유전자 조합 저장, 나중의 옷 변경이 지난 장면에 영향 주지 않음 |
| 23. 부재중 | 최대 현실 8시간, 5분당 상품 하나·최대 60개. 실제 진열 재고에서 차감하고 매출/장부 기록. 이야기 시간은 유지 |
| 24. 담배 | 가상 상품 2개, 판매대 설치·발주, 성인·신분 확인, 꺼내주기와 판매 거절. 자동 부재중 판매 제외 |
| 25. 유지보수·측정 | `catalog.js`, `dialogue-data.js`, `life.js`, `offline.js`, `sound.js`, `lease.js`로 기능 분리. 아래 보고서 스크립트 제공 |

## 실행과 확인

서버 코드가 바뀌었으므로 기존 서버 창에서 Ctrl+C 후 `start.cmd`를 다시 실행하고 브라우저를 새로고침한다. 기존 세이브는 버전 2의 추가 필드 이관을 통해 유지한다. 새 상품 재고는 이관 때 임의로 생성하지 않는다.

- 설정: 시간 흐름, 자동 감속, 소리, 환경/효과 음량
- 사건 패널: 영업일지, 주간 변화, 장면 간직하기
- 발주와 시설: 담배 판매대 설치 후 솔빛 블루/브라운 발주. 다음 입고와 진열 후 구매가 발생
- Ollama: `/local-ai`, 모델 이름 `qwen2.5:3b`
- LM Studio: `/local-lm`, 모델 목록에서 실제 식별자 선택. 서버 기본 포트 1234. 이 경로도 로컬 서버를 거쳐 CORS 설정 불필요

## 검증 명령

```sh
npm.cmd test
npm.cmd run check
node scripts/week-review.mjs
node scripts/model-benchmark.mjs
node scripts/live-model-smoke.mjs
```

`reports/week-review.json`은 세 시드로 각각 게임 시간 21일을 돌려 재고·장부·저장 복원을 확인한다. `reports/model-benchmark.json`은 같은 의도의 규칙 예시와 실제 로컬 모델 응답을 나란히 남긴다. `valid`는 자동 검사 통과를 뜻하며 의미 품질 점수가 아니다. `reports/live-model-smoke.json`은 모델 응답이 게임에 실제 적용되고 재고 집계가 유지되는지 확인한다.

## 남은 검증과 범위

- 실제 브라우저 연결이 없어 PC/모바일 배치, 터치, 두 실제 탭의 UI 전환은 직접 확인하지 못했다. 단일 작성자 동작은 테스트용 Lock Manager로 검증했다.
- 소리 합성 코드를 넣었지만 실제 스피커로 듣는 음량/피로도 검증은 남았다.
- Ollama qwen2.5:3b의 한국어/의미 품질은 고르지 않았다. 자동 검사로 전부 판별할 수 없으므로 사실 전달과 거래 선택은 게임 규칙에 남겼고, 모델은 인사와 잡담 표현만 맡는다.
- LM Studio의 호환 어댑터와 프록시는 구현했으나 실제 LM Studio 서버는 실행 중이 아니었다.
- 생활 변화는 네 가지 초기 유형과 주간 새 이웃이다. 자유로운 이직/이사 서사를 무한 생성하는 기능은 아니다.
- 부재중에는 재고 판매만 정산한다. 게임 시계·관계 장면·배송을 진행시키지 않는다. 신분 확인이 필요한 담배는 부재중 판매하지 않는다.
- 실존 담배 브랜드와 흡연 동작은 넣지 않았다. 게임 내부 성인 판정은 19세 기준의 명시적 규칙이다.
